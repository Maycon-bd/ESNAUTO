# Vocabulário Técnico Central

Use os termos abaixo de forma **consistente e precisa** em todo o texto.
Nunca substitua um termo por sinônimo para variar o estilo — a consistência terminológica é obrigatória.

| Termo | Escopo no TCC |
|---|---|
| **Prototipação de interfaces** | Processo de criação de representações de interfaces (telas, wireframes, fluxos) antes da implementação final |
| **Ferramentas / bibliotecas / frameworks** | As três categorias de soluções analisadas — distinguir quando necessário |
| **Inteligência artificial (IA)** | Técnicas computacionais que automatizam decisões de design; inclui ML, deep learning, LLMs, modelos generativos |
| **Processos ágeis / desenvolvimento ágil** | Metodologias iterativas e incrementais (Scrum, XP, Kanban, etc.) usadas no desenvolvimento de software |
| **Abordagem baseada em código** | Geração ou manipulação de interfaces por meio de código (HTML, CSS, componentes programáticos) |
| **Abordagem baseada em componentes visuais** | Geração ou composição de interfaces por meio de elementos visuais arrastáveis ou gerados graficamente |
| **Geração de telas** | Tarefa automatizada: criação automática de telas ou wireframes a partir de prompts ou dados |
| **Sugestão de componentes** | Tarefa automatizada: recomendação de elementos de UI adequados ao contexto |
| **Recomendações de layout** | Tarefa automatizada: sugestão de organização visual dos elementos na tela |
| **Adaptação de fluxos de navegação** | Tarefa automatizada: ajuste automático dos caminhos entre telas de uma aplicação |
| **Preenchimento de código** | Tarefa automatizada: geração de código de interface a partir de esboços ou especificações |
| **Revisão Sistemática da Literatura (RSL)** | Metodologia estruturada de revisão bibliográfica com protocolo explícito e replicável |
| **Protocolo de revisão** | Conjunto predefinido de regras: questão de pesquisa, critérios de inclusão/exclusão, estratégia de busca |
| **Critérios de inclusão/exclusão** | Regras que determinam quais artigos entram ou saem da seleção final |
| **Extração de dados** | Processo estruturado de coleta de informações dos artigos selecionados, conforme formulário definido |
| **Autonomia da IA** | Grau de independência da ferramenta em relação à intervenção humana |
| **Aplicabilidade ao contexto ágil** | Nível de adequação da ferramenta às práticas e dinâmicas de desenvolvimento ágil |
| **Complexidade de adoção** | Esforço necessário para integrar a ferramenta ao processo de trabalho de uma equipe |
| **XAI (Explicabilidade)** | Métodos que tornam o funcionamento interno dos modelos de IA compreensível para humanos |
| **Nota de corte** | Pontuação mínima de qualidade para inclusão de um artigo na análise final |
